# Lean PRD: 월 예산 설정 및 조회

- 상태: 계획 / 미착수
- 구현 브랜치: `feature/monthly-budget`
- 선행 기준: [전체 PRD](PRD.md), [공통 CLI 보완](PRD-002.md), [월별 요약](PRD-005.md)

## 1. 목적

월별 지출 예산을 영구 저장하고 월별 요약에서 예산 사용률과 초과 여부를 확인한다.
같은 달의 예산을 다시 설정하면 기존 금액을 안전하게 갱신한다.

## 2. 범위

### 포함

- `budget set`을 통한 월 예산 설정·재설정
- `budgets.jsonl` 영구 저장과 월별 조회
- `summary`의 예산 금액·사용률·초과 경고 연동
- `budget`, `budget set` 명령 도움말

### 제외

- 별도 `budget get/list/delete` 명령
- 카테고리별 예산, 미사용 예산 이월, 거래 추가 시 경고

## 3. 사용자 시나리오

옵션 접두사는 [전체 PRD의 CLI 표기](PRD.md#5-cli-표기)를 따른다.

```zsh
python -m budget_app budget set -month 2026-09 -amount 500000
python -m budget_app summary -month 2026-09
python -m budget_app budget set -help
```

설정 성공 시 대상 월과 저장한 예산 금액을 출력한다.
같은 월에 다시 설정하면 기존 금액을 새 금액으로 바꾸며 다른 월은 유지한다.
예산 조회는 `summary`로 통일하고 예산이 설정된 월에만 아래 정보를 추가한다.

```text
예산: 500000원 (사용률 43.0%)
```

총 지출이 예산을 초과한 경우에는 “예산 초과” 경고를 함께 출력한다.
예산이 없는 달에는 기존 월별 요약을 출력하며 사용률이나 초과 경고를 표시하지 않는다.

## 4. 데이터 모델

월별 예산은 `month: str`, `amount: int`의 타입이 명시된 구조로 정의한다.
월은 유일한 키이며 월당 예산은 한 개만 저장한다.

```json
{"month":"2026-09","amount":500000}
```

- `month`: 실제 달력의 연도·월을 나타내는 정확한 `YYYY-MM`
- `amount`: 0보다 큰 정수
- 사용률: 해당 월 총 지출 / 예산 × 100, 출력은 소수점 한 자리
- 초과 여부: 반올림된 사용률이 아니라 원래 정수 금액의 `총 지출 > 예산`으로 판정

총 지출이 예산과 같으면 사용률 100.0%이며 경고를 출력하지 않는다.
실제 지출이 초과했다면 표시 사용률이 반올림되어 100.0%여도 경고를 출력한다.

## 5. 저장 방식

- 공통 데이터 폴더의 `budgets.jsonl`에 UTF-8 JSONL로 저장한다.
- 파일 초기 생성은 PRD-002의 세 저장 파일 초기화 정책을 따른다.
- 새 월은 추가하고 기존 월은 금액을 대체하는 upsert 방식으로 처리한다.
- 기록할 전체 결과를 같은 폴더의 임시 파일에 작성한 뒤 원자적으로 교체한다.
- 기존 월의 중복 행을 만들지 않고 다른 월의 예산은 보존한다.
- 교체 전에 실패하면 원본을 유지하고 임시 파일을 정리한다.
- 조회는 행 단위 제너레이터를 사용하며 거래·카테고리 파일은 수정하지 않는다.

## 6. 구조

- `models.py`: 예산 모델과 JSON 직렬화·역직렬화
- `repositories.py`: `BudgetRepository`의 월 조회·upsert
- `validators.py`: PRD-005 월 검증과 기존 양수 정수 금액 검증 재사용
- `services.py`: 예산 설정과 요약 결과에 대한 사용률·초과 여부 계산
- `cli.py`: `budget set` 옵션과 `summary` 예산 출력

집계된 월 지출은 PRD-005의 결과에서 재사용하며 거래 파일을 추가 순회하지 않는다.
공통 데이터 경로와 오류·종료 코드 정책은 PRD-002를 따른다.

## 7. 주요 검증 규칙

- `budget set`의 `-month`, `-amount`는 모두 필수다.
- 월 형식과 달력 유효성은 PRD-005와 동일하게 검증한다.
- 예산 금액 0·음수·소수·문자열은 오류로 처리하고 기존 예산을 변경하지 않는다.
- 예산이 있고 거래가 없는 달은 “데이터 없음”, 합계 0원, 예산 사용률 0.0%를 출력한다.
- 수입은 예산 사용률에 영향을 주지 않으며 지출만 사용량으로 계산한다.
- 사용률은 100%를 넘어도 실제 값을 표시하며 100%로 제한하지 않는다.

## 8. 완료 조건

표준 라이브러리 `unittest`로 다음 수용 사례를 검증한다.

| 사례 | 기대 결과 |
| --- | --- |
| 새 월 예산 설정 후 재실행 | 월·금액 유지, summary에서 조회 |
| 기존 월 예산 재설정 | 해당 월 한 행만 유지, 새 금액 적용 |
| 다른 월 예산이 있는 상태에서 설정 | 다른 월 예산 보존 |
| 예산 500000원·지출 215000원 | 사용률 43.0%, 경고 없음 |
| 예산과 같은 지출 / 더 큰 지출 | 100.0% 경고 없음 / 초과 경고 |
| 예산 500000원·지출 500001원 | 표시 100.0%여도 초과 경고 |
| 예산만 있고 거래 없는 달 | 데이터 없음·합계 0원·사용률 0.0% |
| 예산 없는 달 또는 수입만 있는 달 | 각각 예산 정보 생략 / 사용률 0.0% |
| 잘못된 월·금액 또는 필수 옵션 생략 | 오류·힌트, 비정상 종료, 기존 파일 유지 |
| 임시 파일 기록 또는 교체 실패 | 기존 예산 보존, 임시 파일 정리 |

summary 예산 연동으로 거래 파일을 다시 집계하지 않는지 확인한다.
관련 테스트와 전체 테스트, Ruff 포맷·검사를 통과하고 README·PROGRESS를 갱신한다.

## 9. 구현 순서

1. 예산 모델과 월 조회·원자적 upsert 저장소를 구현한다.
2. 설정 서비스와 `budget set` CLI를 연결한다.
3. 월별 요약의 예산 표시·사용률·경고를 연결한다.
4. 수용 사례 및 회귀 테스트를 실행하고 문서를 갱신한다.
